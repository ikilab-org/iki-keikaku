## 罠になりそうなもの

- **106条の6は現行と改正後で中身が違う。** 現行＝支援会議、改正後＝小規模市町村地域支援連携協働体制整備事業。支援会議は106条の3の2へ移る。条番号だけで引くと取り違える。ノートは「現行」「改正後」を必ず添えた
- 中間とりまとめ p.9 脚注14 の令和7年度「473 箇所（見込み）」と、予算資料 p.2 の「471」は数が違う。ノートは予算資料に揃えた（論点ページと同じ）
- e-Gov 法令API の XML から第2条を抽出したとき、**附則の第2条が本則の第2条を上書きした。** 本則（MainProvision）に限って再抽出した。同じ番号の条が附則にもある法律では必ず起きる
- pdftotext は「第 106 条」のように数字の前後に空白を入れる。**数字を含む文は鉤括弧で引かず**、数字を含まない部分だけを引いた
- 障がい福祉計画の「相談支援事業所 3か所」は指定事業所の数で、市の委託先の数かは本文から読めない。「委託」の語は使わず「うち1つが社協」とした
- 令和8年3月会議の施政方針PDF（`plans/fukushi/` が引用）は今回取得に失敗し、再確認していない。このノートでは引用しなかった
- `plans/fukushi/` 346行の「属性を問わない相談支援・参加支援・地域づくりに向けた支援の3つを一体的に実施する」は第3次 p.36 の原文と字句が違う（原文は「属性（分野）を問わない相談支援」、「参加支援」及び「地域づくりに向けた支援」の３つの支援を一体的に実施する）。このノートの対象外なので直していない
