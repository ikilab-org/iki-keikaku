# 公共施設等総合管理計画のページを足す（設計）

作成 2026-08-25 ／ 対象 `plans/shisetsu-2036/`（新規）・`data/plans.yml`・`plans/all/`（再生成）・
`index.html`・`README.md`・`sources/MANIFEST.md`・`tools/og/`・`CHANGELOG.md`

外部で書かれた下書き（`shisetsu-2036.html`）を受け取り、リポジトリの規約に載せて公開するまでの設計です。
[2026-08-23 の `plans/koutsuu/` 公開](../../CHANGELOG.md)と同じ流れを踏みます。

## 1. なぜ今これをやるか

**ハブの「これから増やすもの」が、この計画を名指ししています。** 「上位計画とのつながりが強いもの ──
総合計画、過疎地域持続的発展計画、公共施設等総合管理計画など」の3本目です。

`data/plans.yml` には `kokyoshisetsu-sougou`（総合管理計画）と `kokyoshisetsu-kobetsu`（個別施設計画）が
既に入っていますが、どちらも `todo: 計画期間を確認する` が残っています。**掘り下げページを作るには
計画本体を読む必要があり、読めばこの todo は必ず解ける**ので、ページの追加と todo の解消は同じ作業です。

分野の偏りも解消に向かいます。公開中の掘り下げは福祉2本・交通1本で、`domain: gyouzaisei`（行財政運営）は
1本もありません。

## 2. 決めたこと

| 論点 | 決定 |
|---|---|
| 範囲 | **この1ページの追加まで。** 「どの計画をどの深さで掘るか」という一般の編集方針は今回書かない |
| slug | **`plans/shisetsu-2036/`** |
| title | **`壱岐市 公共施設等総合管理計画 ― 1人あたり面積とライフサイクルコスト \| 壱岐市 計画マップ`** |
| 照合 | **`plans/koutsuu/` と同じ全面照合。** 計画本体PDFを取得し、数値・引用・ページ番号をすべて突き合わせる |
| 体裁 | **構造は下書きのまま、色と書体を規約に寄せる。** Google Fonts の読み込みを外す |
| 第Ⅵ章 | **総務省の一次資料で裏を取って残す。** 取れなければ該当箇所を落とす |
| ブランチ | **1本で通す。** ページ追加と `plans/all/` の再生成を同じ差分に含める |

### slug と title を食い違わせる理由

既存3枚（`fukushi` / `kaigo-7-9` / `koutsuu`）は計画名で立てています。この下書きは「2036年」という
**計画の目標年次ではない年**を切り口にしており、下書き自身が第Ⅰ章でそう断っています。

**title は計画名を前に出します。** 検索とタブに出る唯一の手がかりであり、`plans.yml` の
`kokyoshisetsu-sougou` と読み手の中で結びつく必要があるためです。

**slug には 2036 を残します。** このページが扱うのは計画そのものの解説ではなく、
特定の年で切った検算だからです。同じ計画について別の切り口のページが将来必要になったとき、
`plans/koukyoshisetsu/` を空けておけます。`kaigo-7-9` が期を slug に入れているのと同じ考え方です。

### 章立てを既存3枚に合わせない理由

既存の掘り下げは「前提 → 計画 → 実施 → 成果」（介護保険）や「資料 → 推移 → 内訳 → 誰が」（交通）の順で、
**実績が出そろった計画の検証**という形をとっています。

公共施設等総合管理計画は令和4年3月改訂で、削減目標の年次は2041年と2061年です。**検証できる実績が
まだありません。** 下書きは代わりに「計画自身の算定式に、計画自身が併記している人口3系列を代入する」
という検算の構成をとっています。この計画に対してはこちらが正しい形なので、下書きの Ⅰ〜Ⅷ を維持します。

### 3.4 書き換えるもの

**① 第Ⅳ章「必要面積」の丸め。** キャプションは「必要面積＝2036年人口×11.7㎡」と書いていますが、
表の値は 11.6999 で計算されています。

| 人口前提 | 下書き | 11.7 で計算 | 削減率 |
|---|---|---|---|
| 目標人口 22,245人 | 260,264㎡ | **260,267㎡** | 10.9%（変わらず） |
| 社人研推計 19,910人 | 232,945㎡ | **232,947㎡** | 20.2%（変わらず） |
| 社人研準拠 18,815人 | 220,133㎡ | **220,136㎡** | 24.6%（変わらず） |

丸めは四捨五入にそろえます。削減率の結論は動きませんが、**キャプションに書いた式と表の値が
合っていない状態は残しません。**

**② 第Ⅵ章の起債・交付税措置。** 下書きは3項目を「次のような判断が起きやすくなります」として挙げています。
これは制度から予測した行動であって、壱岐市が実際にそう判断したという記述ではありません。
`CONTRIBUTING.md`「守ってほしいこと」6（原因を断定しない）に触れます。

- 出典5「総務省『公共施設等の適正管理の推進』ほか」にはURLがありません。**この章の柱がここに乗っています**
- 一次資料（公共施設等適正管理推進事業債の要綱、地方債同意等基準、除却債の交付税措置の有無）に当たり、
  **URL付きで出典表に載せます**
- 3項目は「こういう判断が起きやすい」から**「制度上こうなっている」という事実の記述に書き換えます。**
  そのうえで、判断への影響は読み手に残します
- 裏が取れなければ**該当箇所を落とします。** 第Ⅵ章の前半（48.5億円の範囲と用語集の定義のずれ）は
  計画本体だけで成立するので、章そのものは残ります

**③ 第Ⅷ章のタグ。** 8項目に、`plans/koutsuu/` の第Ⅵ章と同じ5分類（数値／定義／表記／記録／未公開）を
付けます。2026-08-23 にこの分類へ変えたばかりで、ページ間でタグの意味が食い違うのを避けます。
色は中立色にそろえ、赤（`--crit`）は使いません（介護保険ページで「再発」に使っている注意喚起の色のため）。

**④ 出典表の未処理。** `◆掲載時：各PDFの取得日とSHA-256を付記する。` を照合の結果で埋めます。

**⑤ 調査基準日。** 下書きは 2026年8月24日。照合を実施した日に更新し、フッタと `data/plans.yml` の
`meta.survey_date` をそろえます。

下書きの版面（「先に結論」カード群・章の eyebrow・`pull`／`quote` ブロック・SVGの折れ線）は残し、

| 地の色 | 独自の `--ground` / `--surface` / `--ink` ほか | 既存4枚と同じトークン名・値にそろえる |

`--s1`〜`--s3` は検査に引っかかりませんが、色の値を `assets/palette.css` の1か所に置くという
規約の趣旨から外れるので差し替えます。`plans/koutsuu/` が公開直前に同じ指摘を受けています。

## 5. 照合の手順

`pdftotext` と `pdftoppm` を使います（`plans/koutsuu/` の白文字判定に使ったのと同じ組み合わせ）。

1. 両PDFを取得する。設計時点で到達を確認済み
   - 総合管理計画 `/material/files/group/5/sougoukannrikeikakukaitei.pdf`（200、約4.5MB）
   - 個別施設計画 `/material/files/group/5/kobetusisetukeikakukaitei.pdf`（200、約2.7MB）
2. **取得日と SHA-256、総ページ数、PDF作成日を記録する**
3. `pdftotext -layout` で全文を抽出し、3.2 の表を1件ずつ突き合わせる
4. 鉤括弧の中を一字一句照合し、ページ番号を確認する
5. 3.3 の再計算を、照合後の原本値でやり直す
6. 総務省の一次資料を探す（3.4 ②）
7. **照合の記録を残す。** 合った／原本と違った／原本に見つからなかった を全件、この設計文書に追記する

### 6.1 収録件数は変わらない

両計画とも既に78件に含まれています。`index.html` と `README.md` の総数・機関別内訳・分野タグは
**触りません。** 動くのは todo の件数だけです。

### 6.2 `period` を入れると生成物が動く

`plans/all/` は計画期間タイムラインを持つので、todo を解消すると生成結果が変わります。
**`node tools/build.mjs` を回して生成物もコミットします。** 忘れると CI の `build --check` が落ちます。

このため、ページ追加と俯瞰ページの再生成が同じ差分に混ざります。**分けません。**
照合で確定した計画期間が、ページと俯瞰の両方に同時に反映されるほうが整合が保てるためです。

### 6.3 既存のOGP画像は生成し直さない

`node tools/og/build.mjs` は `CARDS` を全件回します。**新しい1枚だけを残し、既存4枚は `git checkout` で
戻します。** 同じ入力でも Chromium の版と再サンプリングで15%程度の画素が変わり、見た目が同じまま
差分だけが出るためです（2026-08-23 の記録）。

### 6.4 本文中のリンクは死活チェックの対象外

`tools/linkcheck.mjs` が見るのは `data/plans.yml` の `url` / `pdf` / `sources` だけです。
**このページの主要な出典（計画本体PDF2本・掲載ページ2本）は `plans.yml` 側にも置きます。**

## 7. 検証

```bash
node tools/validate.mjs --fail-on-error   # error 0件が必須
node tools/build.mjs                      # plans/all/ を生成し直す（生成物もコミット）
node --test                               # pages.test.mjs がページの骨格を検査
node tools/expiring.mjs                   # todo の件数を数え直す
node tools/manifest.mjs                   # 台帳の未登録を検出
node tools/linkcheck.mjs                  # 追加したURLの死活
```

`tools/pages.test.mjs` は `plans/` 直下を走査するので、テスト側への追加は要りません。
新しいページは自動で検査対象に入ります。

## 8. 工程

1. **照合**（5章）。ここで下書きの数値と引用を原本に突き合わせ、記録を残す
2. **`data/plans.yml`** を更新 → `node tools/build.mjs` → `validate` / `expiring` / `manifest`
3. **`plans/shisetsu-2036/index.html`** を作る（3章・4章）→ `node --test`
4. **OGP** → ハブのカード → `README.md` → `CHANGELOG.md`
5. **`node tools/linkcheck.mjs`**

照合を先に置くのは、原本と合わない数値が出たときにページを作り直さずに済むためです。

## 9. やらないこと

- **「どの計画をどの深さで掘るか」という一般の編集方針の文書化。** 今回の範囲外です
- **個別施設計画の掘り下げ。** 出典としては読みますが、ページの主題は総合管理計画です
- **既存4枚のOGP画像の再生成**（6.3）
- **2036年を新しい目標として提案すること。** 下書きの第Ⅰ章がそう断っており、変えません
- **下書きの主張を守るために照合結果を曲げること。** 原本と合わなければ原本に合わせ、
  直せない箇所は落とします

#### IKILAB計算の再計算

手順5のスクリプトは、**1か所だけ設計時の検算値と食い違いました。**

```

```

`Math.round` が 260266 を返します。**十進で計算すると 260,266.5 で、四捨五入すれば 260,267 です**
（`python3 -c "from decimal import Decimal as D; print(D(22245)*D('11.7'))"` → `260266.5`）。
`p*117/10` に置き換えると期待どおり 260,267 になります。

**3.4 ① の 260,267㎡ が正しい値です。** 他の8件はすべて設計時の検算値と一致しました。

#### 除却の扱い（ここが下書きと食い違う）

A スライド27（⑥ 除却事業）の記載：

> 対象事業　○ 公共施設、公用施設その他の当該地方公共団体が所有する建築物その他の工作物の除却

> ＜参考＞地方財政法（昭和２３年法律第１０９号）※平成２６年度改正（平成２６年法律第５号）により導入
> （公共施設等の除却に係る地方債の特例）
> 附則第３３条の５の８　地方公共団体は、当分の間、公共施設、公用施設その他の当該地方公共団体が所有する建築物その他の工作物（公営企業に係るものを除く。以下この条において「公共施設等」という。）の除却であつて、総務省令で定める事項を定めた当該地方公共団体における公共施設等の総合的かつ計画的な管理に関する計画に基づいて行われるものに要する経費の財源に充てるため、**第五条の規定にかかわらず**、地方債を起こすことができる。

ここまでは下書きの「単独の解体は交付税措置がなく、市の負担が概算10割になる」と整合します。
**しかし、令和7年度に制度が拡充されています。**

B 1枚目：「① 集約化・複合化事業／(2) 集約化・複合化**等**に伴う除却事業（機能統合等に伴うものを含む）**【R７拡充】**」。

B 4枚目の「事例４ 施設の機能を廃止し、除却する場合」は「○（拡充分の対象）」と明記されています。

> ａ 集約化・複合化又は**機能廃止（集約化・複合化又は建替えを行わずに施設の機能を廃止するものをいう。）**（以下「集約化・複合化等」という。）に伴い施設の除却（地財法第33条の５の８に規定する公共施設等の除却をいう。以下同じ。）を行うものであって、当該施設に係る個別施設計画に位置付けられた事業であること。
> ｃ （前略）機能統合（中略）又は**機能廃止に伴う除却である場合においては、除却対象である既存施設の除却が、当該施設の供用廃止から５年以内に行われるものを対象とする**ものであること。
> ｄ 公用施設、公営企業施設及びインフラ施設等を除却する事業は、対象とならないものであること。

**つまり、令和8年度時点でも対象事業の範囲は変わらず、壱岐市が総量削減のために「施設の機能を廃止して壊す」場合、

#### 運用費の扱い

G 第5条の本文（e-Gov法令検索APIから取得した現行条文）：

> （地方債の制限）
> 第五条　地方公共団体の歳出は、地方債以外の歳入をもつて、その財源としなければならない。ただし、次に掲げる場合においては、地方債をもつてその財源とすることができる。
> 一　交通事業、ガス事業、水道事業その他地方公共団体の行う企業（以下「公営企業」という。）に要する経費の財源とする場合
> 二　出資金及び貸付金の財源とする場合（出資又は貸付けを目的として土地又は物件を買収するために要する経費の財源とする場合を含む。）
> 三　地方債の借換えのために要する経費の財源とする場合
> 四　災害応急事業費、災害復旧事業費及び災害救助事業費の財源とする場合
> 五　学校その他の文教施設、保育所その他の厚生施設、消防施設、道路、河川、港湾その他の土木施設等の公共施設又は公用施設の建設事業費（中略）及び公共用若しくは公用に供する土地又はその代替地としてあらかじめ取得する土地の購入費（中略）の財源とする場合

光熱水費・委託料・人件費・日常修繕費はこの5号のどれにも当たらないため、**原則として起債の対象になりません。**
この読み方は2つの傍証で裏打ちされます。

- 除却ですら5条には入らず、**附則第33条の5の8**という特例を立てて初めて起債できるようになった（A スライド27・G）
- E の過疎対策事業債（ソフト分）の説明：「**地方財政法第5条各号に規定する経費に該当しない経費について**、過疎対策事業債をもってその財源とすることができる」

**ただし、その傍証がそのまま限定にもなります。** 壱岐市は過疎地域なので、過疎対策事業債ソフト分という特例があります。
Eの対象は「住民の日常的な移動のための交通手段の確保、地域医療の確保、集落の維持及び活性化その他の住民が将来にわたり
安全に安心して暮らすことのできる地域社会の実現を図るため特別に地方債を財源として行うことが必要と認められる事業
（基金の積立てを含む）」で「※出資及び施設整備費を除く」。充当率100%・交付税措置率70%〈E・令和7年度時点〉です。
施設の光熱水費や清掃委託料が一般にこれに当たるとは読めませんが、**「運用費は全額が一般財源」と言い切ると特例を無視することになります。**
本文では「地方財政法5条の限定列挙に含まれず、**原則として**起債の対象にならない」と書くべきです。

#### 判断

**残す項目**

1. **第Ⅵ章の「建てるほうを選ぶ」の箇条書き。** ただし文言を直します。
   「運用費は全額が一般財源で、起債の対象にならない」→「施設の運用費は地方財政法5条の限定列挙に含まれず、**原則として**起債の対象にならない」。
   建設側は「区分によっては起債と交付税措置の対象になる（壱岐市の場合、過疎対策事業債は充当率100%〈令和8年度告示〉・元利償還金の70%を交付税措置〈令和7年度時点〉）」と、区分を名指しします
2. **出典5の差し替え。** 「総務省『公共施設等の適正管理の推進』ほか」を、上表A〜Hの実URLに置き換えます。年度（令和7年度／令和8年度）を必ず併記します

**落とす項目**

3. **第Ⅵ章の「解体を後回しにする。単独の解体は交付税措置がなく、市の負担が概算10割になる」の箇条書き。**
   一次資料に当たった結果、⑥除却事業に交付税措置がないこと自体は確認できましたが、
   **令和7年度の拡充で「機能廃止に伴う除却」が交付税措置率50%〈措置率は令和7年度資料による〉の対象になっており、
   総量削減で施設を機能廃止して壊す類型は、要件（個別施設計画への位置づけ・供用廃止から5年以内など）を満たせば措置の対象になります。**
   そのまま載せると読者を誤らせます。
   「解体費が更新費の表に現れない」という第Ⅱ章・第Ⅵ章前半の論点は数字で裏が取れているので、
   **財政制度を根拠にした一般化だけを落とします**
4. **合併特例債。** 壱岐市に使えるかを確認できなかったため、本文でも11.2でも根拠に使いません

**第Ⅵ章そのものは残ります。** 前半（48.5億円の範囲と用語集のLCC定義のずれ、範囲が違うと判断が変わる）は
計画本体だけで成立しており、11.1で数値の裏づけが済んでいます。
